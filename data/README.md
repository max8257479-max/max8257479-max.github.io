# Данные Anytime

`anytime_manual.json` — единственный файл, из которого сборщик принимает полные ручные обновления Anytime.

- Для существующей модели можно указать только подтверждённые изменившиеся поля: например `move`, `park`, `specials`, `hourBases`, `hourKms`, `hourExact`, `dayExact`, ставки перерасхода.
- Для новой модели нужен полный объект, совместимый со структурой Anytime в `../tariffs.json`.
- Значения вносятся после просмотра актуальных экранов приложения. Не копируй сюда цены из CarSync как подтверждённые.
- После применения ручная запись остаётся в `anytime_manual.json` и повторно накладывается при следующих ежедневных запусках. Чтобы отменить ручное изменение, удали соответствующее поле или запись из этого файла.

`anytime_watch.json` формируется автоматически из публичного каталога CarSync. Он нужен для обнаружения расхождений и новых моделей, но не является источником расчётов.
