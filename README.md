# Anytime vs Hello — автообновляемая версия

Комплект основан на `cars_calc_anytime_hello_v2_1(2).html` от 23.11.2026.

## Что уже реализовано

- `index.html` сохраняет исходные формулы и алгоритмы калькулятора.
- При открытии веб-версии калькулятор загружает `tariffs.json` без браузерного кеша.
- Если JSON недоступен или открыт локальный `file://`-файл, используются встроенные резервные тарифы.
- Hello: ежедневный сборщик читает официальный каталог `hello.by/cars`, обходит ссылки на модели и обновляет только страницы, где удалось достоверно извлечь ставку движения, стоянки, километра и пакеты. Новые модели добавляются после успешной проверки структуры.
- Anytime: ежедневный сборщик проверяет публичные страницы CarSync, обнаруживает новые модели и расхождения по опубликованным ставкам/пакетам. Эти значения **не подставляются в калькулятор автоматически**, поскольку CarSync — сторонний источник и не содержит полной матрицы часовых тарифов и километража из приложения.
- Полные тарифы Anytime применяются только из `data/anytime_manual.json` после проверки по видео/скриншотам приложения.
- GitHub Actions запускается ежедневно в 08:00 по Минску и вручную по кнопке `Run workflow`.
- Коммит создаётся только при реальных изменениях. Email, Telegram и другие уведомления не настроены.

## Как включить ежедневное обновление

1. Создай новый GitHub-репозиторий или открой репозиторий, где будет размещён калькулятор.
2. Загрузи **всё содержимое этой папки** в корень репозитория, сохранив структуру `.github/workflows`, `scripts` и `data`.
3. В GitHub открой `Settings → Pages`.
4. В разделе Build and deployment выбери `Deploy from a branch`, ветку `main`, папку `/ (root)` и сохрани.
5. Дождись публикации Pages. Открывать калькулятор нужно по веб-ссылке GitHub Pages, а не двойным щелчком по локальному HTML.
6. Открой `Actions → Daily carsharing tariff check → Run workflow`, чтобы выполнить первую проверку сразу.
7. После запуска проверь `tariffs.json` и `data/anytime_watch.json`.

## Важные ограничения

- GitHub Pages нужен для загрузки `tariffs.json` браузером. В локальном HTML автоматическая загрузка соседнего JSON блокируется браузером из-за режима `file://`; расчёт продолжит работать на встроенной копии.
- Публичная страница Anytime сообщает, что это независимый справочник. Она используется только как сигнал для перепроверки, а не как авторитетный источник полной стоимости поездки.
- Для изменения полного набора тарифов Anytime пришли актуальные записи экрана/скриншоты. После проверки значения можно внести в `data/anytime_manual.json`; ежедневная задача применит их к базе.
- Сборщик Hello не меняет профиль скидки: он требует, чтобы страница содержала профиль «Я резидент Беларуси» и «Опыт больше 1 года». Если сайт изменит разметку или профиль, запись не будет автоматически заменена.
- Сборщик сохраняет предыдущие данные при ошибке источника или неполном разборе. Он не подставляет нули и не выводит догадки как подтверждённые цены.

## Ручное обновление Anytime

Файл `data/anytime_manual.json` имеет вид:

```json
{
  "vehicles": {
    "anytime-polo": {
      "tag": "Видео и скриншоты приложения · 2026-12-01",
      "move": 0.33,
      "park": 0.17,
      "specials": {
        "2h": { "label": "1+1 час в подарок", "minutes": 120, "price": 7.99 }
      }
    }
  }
}
```

Это только пример структуры, не новые тарифы. Меняй значения только после проверки в приложении. Для добавления новой модели Anytime нужен полный объект со всеми полями, которые использует калькулятор (см. `anytime-polo` в `tariffs.json`).

## Состав

- `index.html` — калькулятор.
- `tariffs.json` — внешняя база тарифов + исходные подтверждённые значения.
- `scripts/update_tariffs.py` — ежедневный сборщик и проверка данных.
- `data/anytime_manual.json` — подтверждённые ручные обновления Anytime.
- `data/anytime_watch.json` — сигналы по публичным данным Anytime.
- `.github/workflows/update-tariffs.yml` — расписание GitHub Actions.
