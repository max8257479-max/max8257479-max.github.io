# Anytime vs Hello — автообновляемый калькулятор

Проект основан на исходном калькуляторе `cars_calc_anytime_hello_v2_1(2).html` от 23.11.2026. Формулы и алгоритмы расчёта сохранены; тарифная база вынесена в отдельный JSON, который веб-версия загружает без кеша.

## Что обновляется автоматически

- **Hello:** ежедневная проверка официального каталога [hello.by/cars](https://hello.by/cars) и страниц автомобилей. Используется профиль «Я резидент Беларуси», «Опыт больше 1 года». Обновляются только страницы, где сборщик смог извлечь и проверить обязательные тарифные поля. При ошибке страницы предыдущая запись сохраняется.
- **Anytime:** ежедневный мониторинг публичного каталога [CarSync](https://carsync.by/carsharings/anytime) для обнаружения новых моделей и возможных изменений. Это сторонний справочник, не официальный источник полной тарифной матрицы. Его значения **не подставляются в расчёт автоматически**.
- Полные тарифы Anytime меняются только после проверки актуальных видео/скриншотов приложения и внесения подтверждённых значений в `data/anytime_manual.json`.
- Модели с неполными публичными данными могут рассчитываться с пометкой `ориентировочно`, если известна только часть тарифной матрицы. Неизвестные ставки нельзя выдавать за подтверждённые.
- Для Hello модель с URL `/cars/volkswagen-polo` отображается как `Volkswagen Polo без оклейки`.
- GitHub Actions запускается ежедневно в **08:00 по Минску**, вручную и при изменениях кода/ручных данных.
- Email, Telegram и другие уведомления не настроены.

## Публикация сайта

GitHub Actions публикует через GitHub Pages три файла: `index.html`, `app.js` и `tariffs.json`. Браузерный код вынесен в отдельный файл и ограничен Content Security Policy.

Если первая публикация завершится ошибкой конфигурации Pages, открой `Settings → Pages → Build and deployment`, выбери источник `GitHub Actions` и повтори запуск workflow `Daily carsharing tariff check`.

Для локального запуска держи `index.html` и `app.js` в одной папке. В режиме `file://` соседний `tariffs.json` не загружается, поэтому используется встроенная резервная база. Для ежедневного автообновления открывай опубликованную версию GitHub Pages.

## Безопасность

- `app.js` загружается с того же домена; inline JavaScript запрещён CSP.
- Включены `default-src 'self'`, `script-src 'self'`, ограничения `connect-src` и Trusted Types.
- Строки не вставляются в DOM через `innerHTML`; внешние ссылки проверяются по HTTPS и списку разрешённых доменов.
- Сборщик тарифов не следует внешним перенаправлениям и принимает страницы только с доменов Hello и CarSync.
- Python-пакеты фиксируются точными версиями и SHA-256 хешами; CI устанавливает только wheels и запускает `pip-audit`.
- GitHub Actions закреплены по полным SHA. Проверка выполняется с `contents: read`; обновление тарифов и публикация сайта имеют отдельные минимальные права.
- Автоматические тарифные изменения идут через PR, содержащий только `tariffs.json` и `data/anytime_watch.json`. Такой PR объединяется только после успешной проверки.

Для защиты `main` дополнительно включи GitHub Ruleset по инструкции из `SECURITY.md`: обязательный PR, успешный статус `Validate`, запрет force-push и удаления ветки. Для личного аккаунта отдельно включи 2FA/Passkey и проверь активные сессии и SSH-ключи.
## Структура

- `index.html` — разметка калькулятора и Content Security Policy.
- `app.js` — клиентская логика, формулы и резервные тарифы.
- `tariffs.json` — внешняя база тарифов для опубликованной версии.
- `scripts/update_tariffs.py` — сборщик Hello и мониторинг Anytime.
- `data/anytime_manual.json` — подтверждённые ручные обновления Anytime.
- `data/anytime_watch.json` — сигналы из публичного источника Anytime; не используется как тарифная база.
- `tests/test_parsers.py` — тесты парсеров и защиты от SSRF.
- `tests/test_security.py` — проверки CSP и отсутствия небезопасных HTML/JS sinks.
- `requirements.txt` — точные версии Python-зависимостей и SHA-256 хеши wheels.
- `requirements-audit.txt` — отдельный сканер уязвимостей для CI.
- `.github/dependabot.yml` — еженедельные обновления зависимостей.
- `.github/workflows/update-tariffs.yml` — расписание, проверки и публикация GitHub Pages.

## Маршруты из Яндекс.Карт

Калькулятор извлекает координаты из параметра `rtext` и запрашивает автомобильный маршрут у публичного демонстрационного сервера OSRM на данных OpenStreetMap. Это не официальный маршрутизатор Яндекса: время и расстояния могут отличаться от Яндекс.Карт, актуальные пробки Яндекса не учитываются.

Публичный сервер OSRM предназначен для разумного некоммерческого использования, не гарантирует доступность и ограничивает частоту примерно одним запросом в секунду. Калькулятор выдерживает паузу между запросами и не отправляет повторные запросы при неизменной ссылке. Для коммерческого или интенсивного использования потребуется собственный экземпляр OSRM либо отдельный согласованный сервис маршрутизации.

При успешной загрузке импортируются общий километраж, суммарное время движения, время первого и последнего участков и километраж средних участков для абонемента Hello. Все значения можно независимо редактировать; ручные изменения помечаются и не перезаписываются до повторного импорта или загрузки новой ссылки. Время аренды импортируется как чистое время движения; чтобы учесть остановки, увеличь его вручную. Поле «Время на остановках» показывает остаток после вычитания крайних участков и включает движение по средним участкам плюс добавленное время остановок.

## Ручное обновление Anytime

Для существующей модели в `data/anytime_manual.json` можно указать только подтверждённые изменившиеся поля: например `move`, `park`, `specials`, `hourBases`, `hourKms`, `hourExact`, `dayExact` или ставки перерасхода.

Для добавления расчётной модели требуется полный объект со всеми полями, которые использует калькулятор (ориентируйся на объект `anytime-polo` в `tariffs.json`). Неполные публичные цены CarSync можно хранить как частичные расчётные записи, если все неподтверждённые ставки помечены как ориентировочные и источник описывает пробелы в данных.

Пример ниже показывает только структуру, а не реальные цены:

```json
{
  "vehicles": {
    "anytime-polo": {
      "tag": "Проверено по приложению · 2026-12-01",
      "move": 0.33
    }
  }
}
```

Ручные изменения повторно применяются при каждом ежедневном запуске, пока соответствующая запись остаётся в `anytime_manual.json`. Чтобы отменить изменение, удали его из этого файла.

## Защита от ошибочных данных

- При недоступности источника или изменении структуры страницы прежние тарифы сохраняются.
- Новые модели Hello добавляются только после успешной проверки обязательных полей.
- Публичные данные Anytime не заменяют полную тарифную матрицу приложения.
- При недоступном или повреждённом `tariffs.json` калькулятор продолжает работу на встроенной резервной базе.
