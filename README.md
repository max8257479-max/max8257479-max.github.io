# Anytime vs Hello — автообновляемый калькулятор

Проект основан на исходном калькуляторе `cars_calc_anytime_hello_v2_1(2).html` от 23.11.2026. Формулы и алгоритмы расчёта сохранены; тарифная база вынесена в отдельный JSON, который веб-версия загружает без кеша.

## Что обновляется автоматически

- **Hello:** ежедневная проверка официального каталога [hello.by/cars](https://hello.by/cars) и страниц автомобилей. Используется профиль «Я резидент Беларуси», «Опыт больше 1 года». Обновляются только страницы, где сборщик смог извлечь и проверить обязательные тарифные поля. При ошибке страницы предыдущая запись сохраняется.
- **Anytime:** ежедневный мониторинг публичного каталога [CarSync](https://carsync.by/carsharings/anytime) для обнаружения новых моделей и возможных изменений. Это сторонний справочник, не официальный источник полной тарифной матрицы. Его значения **не подставляются в расчёт автоматически**.
- Полные тарифы Anytime меняются только после проверки актуальных видео/скриншотов приложения и внесения подтверждённых значений в `data/anytime_manual.json`.
- Модели с неполными публичными данными могут храниться с `infoOnly: true`: калькулятор показывает их известные цены справочно, но не включает в расчёт и рейтинг до подтверждения полной матрицы в приложении.
- GitHub Actions запускается ежедневно в **08:00 по Минску**, вручную и при изменениях кода/ручных данных.
- Email, Telegram и другие уведомления не настроены.

## Публикация сайта

GitHub Actions автоматически собирает и публикует через GitHub Pages только два файла: `index.html` и `tariffs.json`. Веб-версия загружает актуальный JSON рядом с HTML.

Если первая публикация завершится ошибкой конфигурации Pages, открой `Settings → Pages → Build and deployment`, выбери источник `GitHub Actions` и повтори запуск workflow `Daily carsharing tariff check`.

Открывай калькулятор по адресу GitHub Pages, а не двойным щелчком по локальному HTML. В режиме `file://` браузер блокирует загрузку соседнего JSON, поэтому калькулятор использует встроенную резервную базу.

## Структура

- `index.html` — калькулятор, формулы и резервные тарифы.
- `tariffs.json` — внешняя база тарифов для опубликованной версии.
- `scripts/update_tariffs.py` — сборщик Hello и мониторинг Anytime.
- `data/anytime_manual.json` — подтверждённые ручные обновления Anytime.
- `data/anytime_watch.json` — сигналы из публичного источника Anytime; не используется как тарифная база.
- `tests/test_parsers.py` — тесты парсеров.
- `.github/workflows/update-tariffs.yml` — расписание, проверки и публикация GitHub Pages.

## Ручное обновление Anytime

Для существующей модели в `data/anytime_manual.json` можно указать только подтверждённые изменившиеся поля: например `move`, `park`, `specials`, `hourBases`, `hourKms`, `hourExact`, `dayExact` или ставки перерасхода.

Для добавления расчётной модели требуется полный объект со всеми полями, которые использует калькулятор (ориентируйся на объект `anytime-polo` в `tariffs.json`). Неполные публичные цены CarSync можно хранить только как `infoOnly: true` с блоком `publicRates`; такие записи показываются справочно и исключены из расчёта.

Пример ниже показывает только структуру, а не реальные цены:

```json
{
  "vehicles": {
    "anytime-polo": {
      "tag": "Проверено по приложению · 2026-12-01",
      "move": 0.33
    }
  }
}
```

Ручные изменения повторно применяются при каждом ежедневном запуске, пока соответствующая запись остаётся в `anytime_manual.json`. Чтобы отменить изменение, удали его из этого файла.

## Защита от ошибочных данных

- При недоступности источника или изменении структуры страницы прежние тарифы сохраняются.
- Новые модели Hello добавляются только после успешной проверки обязательных полей.
- Публичные данные Anytime не заменяют полную тарифную матрицу приложения.
- При недоступном или повреждённом `tariffs.json` калькулятор продолжает работу на встроенной резервной базе.
